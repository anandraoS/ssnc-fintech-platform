# API examples (captured from the running application)

Generated by `scripts/capture-api-examples.mjs` against the local stack - every response below is real output; JWTs and correlation ids
are redacted. Base URL `http://localhost:18480`. Money amounts are strings. See `specs/openapi.json` for the full contract.

### Customer management: create a customer (operations/admin)

Customers are created by staff. `taxIdLast4` is accepted but never returned (`****`).

```http
POST /api/v1/customers
Content-Type: application/json
Authorization: Bearer <jwt>

{
  "legalName": "Frida Example",
  "email": "frida-1792335216662@example.test",
  "phone": "+1-555-0199",
  "taxIdLast4": "9999"
}
```
