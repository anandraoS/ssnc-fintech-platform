# Job-description traceability matrix

Maps each major requirement of a **Senior/Lead Java Full-Stack Engineer** role (as described for SS&C FinTech Services India, Hyderabad - full-stack Java with Spring Boot, Angular or React, REST, microservices,
SQL/Oracle/MongoDB, automated testing, TDD/BDD, secure coding, CI/CD, cloud, AI-assisted engineering, technical ownership) to **concrete evidence in this repository**.
Rule applied: *a requirement counts as demonstrated only when it is tied to code, tests, scripts, or clearly labelled conceptual material.* "Evidence" states whether it was **executed** (E),
**statically validated** (S), or is **conceptual** (C). The frontend exists twice, in Angular (`frontend/`) and in React (`frontend-react/`), against the same API. No claim here is made about any vendor's proprietary systems.
